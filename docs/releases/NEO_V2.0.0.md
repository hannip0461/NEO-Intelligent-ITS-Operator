# NEO v2.0.0 릴리즈 기록

배포일: 2026-08-03  
상태: GitHub, Docker Hub, AWS 배포 및 검증 완료  
서비스 주소: `https://3-38-33-156.sslip.io/neo`

## 릴리즈 범위

- 감시 화면을 사건, 판단 근거, 현재 조치 중심으로 재구성
- 보류·오탐 처리에 확인 절차와 운영자 사유 기록 추가
- 계보 기본 화면을 전체 그래프로 고정하고 선택·판단 경로 전환 시 배치 유지
- 예지·이상 분석에 단계별 진행 상태, 수치 축, 허용 범위와 결과 우선순위 적용
- 이력·상태·정책 화면의 정보 밀도, 긴 식별자, 상세 열기 흐름 개선
- 판단 설명과 예측 요청에 시간초과, 취소, 재시도 상태 추가
- LSTM 요청별 재학습을 제거하고 기동 시 준비한 모델로 추론하도록 변경
- PC·모바일 6개 화면과 선택·확인·취소·복귀 상호작용 재검증

핵심 규칙 엔진과 Rule KB는 비공개로 유지하고, 공개 GitHub 저장소에는 화면과 설계·배포 문서만 게시했다.
